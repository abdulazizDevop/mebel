## Что уже автоматизировано на сайте

| Действие | Где | Что происходит в системе |
|---|---|---|
| Отказ от рекламы / подписка | Профиль → «Согласия и данные» → «Отказаться» | `customers.marketing_allowed = false`, строки `consent_logs` типа `marketing` → `revoked` с датой; `POST /consents/withdraw` |
| Удаление аккаунта | Профиль → «Удалить аккаунт» (с подтверждением паролем) | учётная запись удаляется; заказы остаются обезличенными от аккаунта (`customer_id = NULL`) на основании договора; push-подписки удалены; согласия помечены отозванными и отвязаны (`request_id = deleted:<id>`) |
| Просмотр своих согласий | `GET /consents/me` (по токену покупателя) | только чтение |
| Изменение настроек cookie | футер → «Настройки cookie» | локально + запись в `consent_logs` (`analytics_cookie`, `marketing_cookie`) |

## Ручной порядок (владелец)

1. **Регистрация обращения.** Зафиксировать дату получения, канал, суть запроса, контакт заявителя (таблица «Обращения субъектов» — файл у владельца, не в репозитории).
2. **Идентификация заявителя.** Данные хранятся по имени (логину) и телефону заказа. Запросить у заявителя: имя, использованное на сайте, и номер телефона из заказа / номер заказа. Если данные не совпадают с записями — вежливо отказать в выдаче сведений (нельзя раскрывать данные третьему лицу) и предложить уточнить.
3. **Поиск данных.** Панель администратора → Заказы (фильтр по телефону). Для регистрации: `customers` по имени; для согласий: `consent_logs` по `customer_id` / `request_id`.
   Быстрый SQL на сервере (`/opt/mebel`):
   ```bash
   docker compose exec db psql -U mebel -d mebel -c "SELECT id, customer_name, customer_phone, status, created_at FROM orders WHERE customer_phone LIKE '%<цифры>%';"
   docker compose exec db psql -U mebel -d mebel -c "SELECT consent_type, document_version, source_form, status, created_at, revoked_at FROM consent_logs WHERE customer_id = '<id>' OR request_id = '<order_id>';"
   ```
4. **Выполнение.**
   - Информация: ответить письмом на e-mail заявителя по шаблону ниже (перечень данных, цели — со ссылкой на /privacy, срок хранения, кому передавались — перевозчик, если был).
   - Уточнение: исправить имя/телефон в заказе через панель (или SQL), ответить.
   - Удаление/отзыв: если у заявителя есть аккаунт — попросить воспользоваться кнопкой «Удалить аккаунт» либо удалить самостоятельно по его письменному запросу; заказы без завершённых обязательств — обезличить (`customer_name = 'Покупатель'`, `customer_phone = '***'`), файлы чата удалить из S3; заказы с действующими обязательствами/гарантией — сообщить, что данные хранятся на основании договора до истечения срока (data-retention-policy.md).
   - Реклама: если аккаунта нет — поставить пометку в таблице обращений и не звонить/не писать с рекламой; при наличии аккаунта — `marketing_allowed = false`.
5. **Ответ заявителю** — в срок из таблицы выше, тем же каналом. Сохранить копию ответа.
6. **Журнал.** Записать дату исполнения и что сделано. Хранить 3 года.
