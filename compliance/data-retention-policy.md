# Политика сроков хранения персональных данных — rooomebel.ru

Оператор: Басханов Рамазан Загирович, ИНН 054400624877. Дата: 06.09.2026.
Принцип (ст. 5 ч. 7 152-ФЗ): данные хранятся не дольше, чем требует цель обработки, если иной срок не установлен законом или договором; по истечении срока — удаляются или обезличиваются.

| Данные | Срок хранения | Отсчёт | Что происходит по истечении | Кто выполняет |
|---|---|---|---|---|
| Учётная запись покупателя (`customers`) | до удаления пользователем | кнопка «Удалить аккаунт» в профиле или запрос на e-mail | строка удаляется, заказы отвязываются (`customer_id = NULL`), push-подписки удаляются | автоматически (`POST /auth/customer/me/delete`) |
| Заказы, позиции, чат по заказу (`orders`, `order_items`, `chat_messages`) | **3 года** после завершения/отмены заказа | `orders.created_at` / статус `completed`, `cancelled` | обезличивание: `customer_name → «Покупатель»`, `customer_phone → «***»`, файлы чата удаляются из S3 | владелец, ежеквартально (ручной скрипт — задача владельца; см. compliance-report.md) |
| Журнал согласий (`consent_logs`) | **3 года** после отзыва согласия или удаления аккаунта (срок исковой давности, ст. 196 ГК РФ — доказательство правомерности обработки) | `revoked_at` | удаление строк | владелец, ежеквартально |
| События аналитики (`analytics_events`) | **12 месяцев** | `created_at` | удаление | владелец, ежеквартально |
| Push-подписки (`push_tokens`) | пока действует подписка | отписка в интерфейсе, удаление аккаунта, ответ 404/410 от push-сервиса | удаление строки | автоматически |
| Access-логи nginx / uvicorn (IP, User-Agent, URL) | **14 дней** | ротация | удаление | `logrotate` на сервере + `docker logs` с ограничением размера — **задача владельца** (см. security-checklist.md) |
| Резервные копии БД | 30 дней, шифрованные, в РФ | дата снимка | удаление старых снимков | **не настроено** — задача владельца |
| Согласие на рекламу (`customers.marketing_allowed`) | до отзыва | кнопка «Отказаться» в профиле / e-mail | флаг `false`, строка согласия → `revoked` | автоматически |
| Cookie-предпочтения и visitor-id в браузере | до очистки браузера пользователем | — | — | пользователь |

## Как выполнить удаление / обезличивание по истечении срока

Скрипт-заготовка для владельца/разработчика (выполнять на сервере в `/opt/mebel`):

```bash
docker compose exec db psql -U mebel -d mebel <<'SQL'
-- заказы старше 3 лет: обезличить контактные данные
UPDATE orders SET customer_name = 'Покупатель', customer_phone = '***'
 WHERE created_at < now() - interval '3 years' AND customer_phone <> '***';
-- журнал согласий: удалить строки, отозванные более 3 лет назад
DELETE FROM consent_logs WHERE revoked_at IS NOT NULL AND revoked_at < now() - interval '3 years';
-- аналитика старше 12 месяцев
DELETE FROM analytics_events WHERE created_at < now() - interval '12 months';
SQL
```

Файлы чата (фото/голосовые) обезличенных заказов удаляются из бакета `rooomebel` вручную или скриптом по префиксу `chat/` — задача владельца.
