## 6. Как проверить самому после деплоя

1. Открыть https://rooomebel.ru — внизу баннер cookie с тремя кнопками; «Настроить» открывает окно с ВКЛ/ВЫКЛ.
2. Футер: реквизиты + 8 ссылок + «Настройки cookie»; все страницы открываются.
3. Профиль → Регистрация: без галочки «Я даю согласие…» — ошибка «Необходимо согласие на обработку персональных данных».
4. Корзина → Оформить → без галочки «Я ознакомился…» — ошибка; с галочкой — экран «Заказ принят» с номером и составом.
5. Профиль (после входа): карточка «Согласия и данные» — «Отказаться/Подписаться», «Удалить аккаунт» с паролем.
6. DevTools → Application → Cookies: без согласия нет cookie `_ym_*`; после «Принять» и при заданном счётчике — появляются.
7. Сервер: `cd /opt/mebel/backend && ../backend/.venv/bin/python -m pytest` не нужен — тесты запускаются локально разработчиком; на сервере достаточно `docker compose run --rm api alembic current` = `7c9d2e4f1a6b`.
