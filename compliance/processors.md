# Сторонние сервисы и обработчики — rooomebel.ru

Проверено по коду 06.09.2026 (grep по `backend/`, `src/`, `index.html`, `deploy/`, `docker-compose.yml`). Для каждого сервиса из ТЗ §24 указано: используется ли, какие данные получает, цель, страна, где хранит, когда запускается, нужно ли согласие, есть ли трансграничная передача, риск.

## Используются

| Сервис | Данные | Цель | Страна / хранение | Когда запускается | Согласие | Трансграничная передача | Риск | Что сделать владельцу |
|---|---|---|---|---|---|---|---|---|

## Не используются (проверено)

| Сервис | Статус |
|---|---|
| Google Analytics / Google Tag Manager / Google Fonts | нет. Google Fonts удалён — шрифт Onest самохостится (`@fontsource/onest`) |
| Meta Pixel / Facebook SDK | нет |
| Firebase, Supabase | нет |
| Sentry или иной трекер ошибок | нет |
| Cloudflare / CDN | нет (статика отдаётся собственным nginx) |
| reCAPTCHA | нет (защита — rate limiting `slowapi`) |
| Карты (Яндекс/Google Maps) | нет |
| Онлайн-чат сторонний (JivoSite и т. п.) | нет — собственный чат внутри сайта |
| Telegram-бот, e-mail-рассылка (SMTP/SendGrid), SMS-шлюз | нет |
| CRM | нет |
| Платёжные сервисы (эквайринг) | нет — оплата согласуется вне сайта |
| API служб доставки | нет — передача перевозчику вручную владельцем |

## Кому передаётся вручную (вне кода)

- Перевозчики/службы доставки — имя, телефон, адрес получателя в объёме, необходимом для доставки (договор).
- Никому более. Продажа/передача базы для чужих целей не производится.

## Требуется от владельца (ТРЕБУЕТСЯ ДЕЙСТВИЕ ВЛАДЕЛЬЦА)

1. Подтвердить наличие договора/оферты с TimeWeb (хостинг + S3) и сохранить копию.
2. Принять решение по Webvisor (рекомендация — не включать).
3. Если появятся эквайринг, SMS, e-mail-рассылка, CRM, доставка по API — дополнить эту таблицу и Политику (раздел 8 «Передача третьим лицам») **до** подключения.
